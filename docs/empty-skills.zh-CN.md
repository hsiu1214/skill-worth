# AI 技能市场里的空壳

> 我抽查了市集上安装量最高的 30 个 skill，其中 3 个什么也不做——而这 3 个合计被安装了 10.5 万次。

## 一、先说一个具体发现

市集上有个叫 `summarize` 的 skill，安装量 **45,959**。

它的全部内容是 **2 个文件、3,558 字节**，没有一行代码。里面的 `SKILL.md` 写着这样一句：

> 本技能由规划规格 README 自动落地生成，操作细节（具体 API/CLI/连接）应在接入真实运行时补全。

也就是说，**作者自己就写明了这东西还没做完**。

它能做什么？文件里列着「支持网页、PDF、Word、TXT、播客、YouTube 视频摘要」。而我实测过：这台机器上没有 `yt-dlp`、没有 `ffmpeg`、没有 `whisper`——它宣称的功能一样都跑不起来。

四万五千个人装了它。

## 二、怎么测的（口径先讲清）

我不想靠印象说「市集上很多水货」，所以做了一次抽样：

| 项目 | 说明 |
|---|---|
| 样本 | 市集安装量 ≥500 的 skill，按安装量降序取前 30 |
| 来源 | 总榜 TOP50 + 11 个类目榜，去重后池子 207 个 |
| 方法 | 逐个下载 zip、解压、**静态检查，不执行任何代码** |
| 判定 | 五维加权（实质功能 40 / 宣称为实 25 / 说明清楚 15 / 安全 10 / 维护 10） |

**统计口径**：28 个成功扫到，2 个包的存储端返回损坏 zip（不计入）。结论只代表**本次下载到的那份包**——同一个名字可能有多个发布者，版本内容也可能变过。

## 三、结果

| 判定 | 数量 |
|---|---|
| 值得装 | 24 |
| 看你要什么 | 1 |
| **别装（空壳）** | **3** |

这 28 个合计被安装 **551,968** 次。其中被判「别装」的那 3 个，占了 **104,762** 次。

比例是 11%。不算灾难，但考虑到样本全是**安装量 500 以上的热门 skill**，这个数字不太好看。

## 四、最有意思的部分：它们是同一个模子刻的

三个空壳分别是 `summarize`（45,959）、`skill-vetter`（37,273）、`weather`（21,530）。

功能完全不同，但**判定理由一字不差**：

> 作者自己写明：操作细节还没实作

三个都是同样的分数（28）、同样的失败原因、同样的结构——「分类：X 类」「技能类型：X」「风险等级：低」「门禁档位：L0」这几行，然后是一堆放在任何 skill 上都成立的套话（「先确认输入来源」「保持样式一致」「批量处理前先用样本验证」）。

再看来源：**三个全部来自 `@clawhub_*` 镜像**，更新记录都是同一句 `Synced by skillhub pipeline`。

三个不同作者、三种不同功能，产出物结构一模一样。这不是巧合，是**同一条流水线批量生成的**。

## 五、为什么安全扫描器抓不到它们

这一年出了不少 skill 安全工具，做得都比我好：NVIDIA 的 SkillSpector（68 种漏洞模式、YARA 签名、污点追踪）、Snyk 的 agent-scan、Cisco 的 skill-scanner。**该用就用。**

但它们回答的是「这个东西危不危险」。而空壳的答案是：**完全不危险**。

- 没有恶意代码 → 不报
- 没有网络请求 → 不报
- 没有读取 `~/.ssh` → 不报
- 没有硬编码密钥 → 不报

一个什么都不做的 skill，在安全扫描器眼里是**满分好公民**。它确实不偷东西，它什么都不拿，因为它什么都不做。

这两种问题性质不同：
- 安全问题：**它会害你**
- 空壳问题：**它骗你的时间**

## 六、不用任何工具，四步就能自己判断

如果你只是偶尔装个 skill，不必上工具，看四件事就够：

**1. 先看有没有代码文件**

不是说没代码就是假的——检查清单、写作方法、诊断流程这类，价值本来就在文字里。要看它**说的是哪种**。

**2. 看它说「教你判断」还是「帮你做」**

- 说「这里是审查 skill 的四个步骤」→ 知识型，没代码正常
- 说「爬取 16 个引擎并合并结果」→ 动手型，没代码就是空的

**3. 搜这几个词**

在 `SKILL.md` 里搜「待补全」「自动生成」「接入真实运行时」「to be implemented」。**作者自己承认没写完的，通常真的没写完。**

**4. 看它提到的文件在不在**

很多 skill 会写「运行 `scripts/foo.py`」。去目录里看看这个文件存不存在。我扫过的样本里，有的 skill 提到的文件一半都找不到。

## 七、这件事真正的影响

空壳不像恶意代码那样上新闻，但它的累积效应更隐蔽：

一个用户装了三个空壳，试了两次没效果，就会得出「AI 技能这东西是玩概念的」的结论，然后再也不装任何 skill——包括那些真正做得好的。

**劣币驱逐良币，靠的不是质量更差，而是名字更响。**

## 附：工具

上面这套判定我写成了一个小工具，叫 [skill-worth](https://github.com/hsiu1214/skill-worth)，MIT 协议，零依赖。

```bash
pip install git+https://github.com/hsiu1214/skill-worth.git
skill-worth check ./some-skill
```

但它只是把上面那四步自动化而已。**如果你已经会判断，不需要它。**
